مشروع واحد يجمع بين:
- بوت تيليجرام لربط أرقام واتساب عبر كود الاقتران.
- التفاعل التلقائي مع حالات واتساب.
- موقع رسمي فاخر ومتجاوب.
- نظام تعليقات واستفسارات داخل الموقع.
- لوحة مطور للرد على التعليقات.
- إحصائيات كاملة مباشرة من نفس قاعدة بيانات البوت.
- إرسال رابط الموقع داخل الرسائل التلقائية بعد الربط أو استعادة الجلسة.

## أهم متغيرات البيئة
انسخ `.env.example` إلى `.env` ثم عدل القيم التالية:
- `TELEGRAM_TOKEN` توكن بوت تيليجرام.
- `MONGODB_URI` رابط MongoDB.
- `MONGODB_DB_NAME` اسم قاعدة البيانات.
- `SESSION_STORAGE_MODE=database` لحفظ الجلسات داخل القاعدة فقط.
- `WRITE_LOCAL_STATE_CACHE=false` لتعطيل أي كتابة محلية غير ضرورية على Railway.
- `MONGO_POOL_SIZE=80` قيمة مناسبة مبدئياً للأعداد الكبيرة.
- `RESUME_CONCURRENCY=12` و `RESUME_BATCH_DELAY_MS=250` لتحسين استعادة 300+ جلسة.
- `LOG_LEVEL=warn` لتقليل السجلات في بيئة الإنتاج.
- `MEDIA_DOWNLOAD_DIR` مجلد تنزيلات تيك توك / إنستغرام المؤقتة.
- `MEDIA_MAX_SIZE_MB` الحد الأعلى لحجم الفيديو المسموح إرساله.
- `MEDIA_DOWNLOAD_TIMEOUT_MS` مهلة تنزيل الفيديو قبل الإلغاء.
- `MEDIA_REQUEST_TIMEOUT_MS` مهلة طلبات الجلب الخفيفة (HTML / API / فحص الروابط).
- `MEDIA_FETCH_CACHE_TTL_MS` مدة كاش نتائج تجهيز الروابط لتقليل الضغط على الخادم.
- `MEDIA_WARMUP_INTERVAL_MS` مدة إعادة تسخين مصدر تيك توك لتقليل فشل الطلبات.
- `YT_DLP_BINARY_PATH` مسار yt-dlp إذا كان مثبتاً مسبقاً على الخادم (اختياري).
- `TIKTOK_SOURCE_PREFIX` و `TIKTOK_SOURCE_SITE` و `TIKTOK_SOURCE_API` إعدادات مصدر TikTokIO لاستخراج روابط تيك توك المباشرة.
- `INSTAGRAM_SESSIONID` أو `INSTAGRAM_COOKIES` أو `INSTAGRAM_COOKIES_FILE` لتحسين دعم بعض روابط إنستغرام العامة التي تتشدد أحياناً.
- `INSTAGRAM_APP_ID` قيمة رأس طلب إنستغرام المستخدمة أثناء الجلب.
- `WEBSITE_URL` رابط موقعك النهائي بعد النشر.
- `SITE_ADMIN_TOKEN` رمز الدخول إلى لوحة المطور بالموقع.
- `DEVELOPER_WHATSAPP` رقم المطور.
- `AI_CHAT_ENABLED` تفعيل أو تعطيل صفحة المساعد الذكي.
- `AI_CHAT_ENDPOINT` ربط واجهة المساعد بأي API خارجي إن رغبت، وإذا تُرك فارغاً فسيعمل المساعد الداخلي العربي المدمج.
- `AI_CHAT_API_KEY` مفتاح التوثيق للواجهة الخارجية إن كانت مطلوبة.
- `AI_CHAT_SYSTEM_PROMPT` تعليمات مخصصة للمساعد الخارجي.
- `AI_CHAT_MAX_PROMPT_CHARS` أقصى طول لرسالة المستخدم في صفحة المساعد.

## تخزين الجلسات
- كل رقم مربوط يمتلك معرّف جلسة مستقل بالشكل `wa_session_{userId}_{number}`.
- ملفات اعتماد واتساب لكل رقم تُحفظ داخل MongoDB بشكل معزول تحت نفس معرّف الجلسة.
- بيانات الرقم نفسه (الحالة، الإيموجي، إعدادات التفاعل، وقت الربط) تُحفظ أيضاً كسجل مستقل داخل مجموعة `wa_sessions`.
- بهذا الشكل تكون كل جلسة مع إعداداتها منفصلة منطقياً داخل قاعدة البيانات.

## أوامر التحميل الجديدة داخل الرقم المربوط
- `.tt <link>` لتحميل فيديو تيك توك بدون علامة مائية.
- `.ig <link>` لتحميل فيديو إنستغرام.
- `.dl <link>` لتحميل أي رابط مدعوم من تيك توك أو إنستغرام.
- كذلك إذا أرسل أي شخص رابط تيك توك أو إنستغرام مباشرة إلى الرقم المربوط، سيرد الرقم تلقائياً بالفيديو بعد تنزيله.

## ملاحظات مهمة
- إن أردت الاعتماد الكامل على قاعدة البيانات في Railway فاضبط `SESSION_STORAGE_MODE=database` ووفّر `MONGODB_URI` صحيحاً.
- `PROCESS_HISTORY_STATUSES=false` يمنع معالجة الحالات القديمة عند إعادة التشغيل ويخفف الضغط بشكل كبير.
- عند استخدام أعداد كبيرة من الأرقام، اترك `LOG_LEVEL=warn` أو `error`.
- عند تشغيل المشروع ستعمل واجهة الويب والبوت من نفس التطبيق.
- أول عملية تحميل فيديو قد تستغرق وقتاً إضافياً بسيطاً إذا احتاج الخادم لتنزيل ملف `yt-dlp` التنفيذي تلقائياً.
- تم تحسين التحميل بحيث يحاول أولاً استخراج رابط مباشر لفيديو TikTok عبر TikTokIO، ولإنستغرام عبر الصفحة نفسها أو واجهة embed/json أو ddinstagram، ثم يعود تلقائياً إلى `yt-dlp` كخطة احتياطية.


## الحماية العربية للرقم المربوط

أضيفت حماية مستقلة لكل رقم مربوط، وتُحفظ في قاعدة البيانات مع إعدادات الرقم:

- `.منع_الروابط تشغيل` أو `.منع_الروابط ايقاف`: عند التشغيل تُحذف الروابط في المجموعات، ويُرسل تنبيه «ممنوع إرسال الروابط هنا»، ويُمنح المرسل 3 تحذيرات، وبعد التحذير الثالث يُحظر ويُزال إن كان الرقم المربوط مشرفاً.
- `.منع_الاضافة تشغيل` أو `.منع_الاضافة ايقاف`: عند التشغيل إذا أُضيف الرقم إلى مجموعة يغادرها فوراً ويرسل لمنفذ الإضافة «لا يمكنك إضافة رقمي إلى مجموعة». لا يوفر واتساب حدثاً لإلغاء الإضافة قبل وقوعها، لذلك التنفيذ الصحيح هو المغادرة الفورية.
- `.منع_الخاص تشغيل` أو `.منع_الخاص ايقاف`: عند التشغيل تُحذف الرسائل الخاصة الواردة تلقائياً بلا تحذير.
- `.حماية_الكل`: عرض أوامر الحماية العربية.

تظل الأوامر محصورة برسائل مالك الرقم نفسه، وتعمل كل إعدادات الحماية لكل رقم بشكل مستقل.
